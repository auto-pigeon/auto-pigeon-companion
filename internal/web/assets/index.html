                                      Updates
                                      
            
                                      
              The Companion installs Auto-Pigeon's own builds of EricW tools and
              q3map2 from their GitHub releases on first launch, and checks for
              new versions of them and of itself about once an hour while it
              runs. Updates are offered, never applied unasked; "Don't ask again"
              skips only that version. An update waits for builds, downloads and
              games to finish. A SHA-256 published in the same release shows each
              download is intact; these builds are not signed. Programs you set up
              yourself are left as they are.

                                        About Auto-Pigeon Companion
                                        
        
      
                                        
      
                                        
        The Companion turns the maps you make in Auto-Pigeon into maps you can play.
        It runs on your own computer, next to the game you already have.
      
                                        
      
                                        
        Choose a map from your account and press Build & Run: the Companion
        downloads that exact version and its textures, compiles it with the map tools you choose,
        installs it in a folder of its own beside the game, and starts the game on it.
      
                                        
      
                                          
        
                                        • Your game stays yours. The Companion never changes the game's own folders and never ships a game or its data.
                                          • 
        
                                        • Nothing runs without your say. Every tool and engine is described by a profile you read and approve before it can start.
                                          • 
        
                                        • Everything is on the record. Every program it runs, with its exact command and output, is kept under Jobs.
                                          • 
        
                                        • Play together. Host a map and it shows in Live Games, where others can join it.
                                          • 
      
                                        
      
                                        
        Map-building tools and game engines are separate programs under their own licences,
        which you install yourself and which run as their own processes — see THIRD_PARTY_NOTICES.md in the Companion's repository.
        The Companion's own code is MIT-licensed; the Auto-Pigeon Extractor shipped beside it is proprietary, under its own licence.
